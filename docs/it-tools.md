# IT tools

The **IT Tools** tab (next to Topology, or **View → IT tools**) holds calculators that work on their own and, where useful, on the open project. Click any result to copy it.

| Tool | Use it to… |
|---|---|
| **Subnet calculator** | Get the network, mask, wildcard, broadcast and host range of a prefix; split it into smaller subnets; summarise routes. **Add to project** creates the subnet. |
| **VLSM** | Turn a list of `Name, hosts` lines into right-sized subnets. **Create in project…** opens the VLSM planner with them. |
| **IPv4 / IPv6 notation** | Convert between compressed, expanded, integer, hex and binary forms; get the reverse-DNS name; build a SLAAC address from a prefix and a MAC. |
| **MAC vendor lookup** | Find the manufacturer of a MAC address or OUI from the IEEE registry. It also lists every MAC recorded in the project with its vendor. |
| **Transfer time** | Work out how long a backup or copy takes over a link, allowing for protocol overhead, and the speed you'd need for a time window. |
| **Oversubscription** | Compare edge capacity with uplink capacity, against common guidance (20:1 for access, 4:1 for distribution). It also lists every switch in the project. |
| **Fibre loss budget** | Add up fibre, connector, splice and margin loss against the optic's limit. It also lists every fibre run in the project. |
| **PoE budget** | Compare the power reserved by class with the expected draw against a switch's budget. **Load from switch** fills it from the project. |
| **Port reference** | Look up about 100 well-known TCP/UDP ports and protocols, with risky clear-text services flagged. |
| **Bill of materials** | List hardware by model, optics, cable by type with slack, and racks. Copy it or save it as CSV. |
