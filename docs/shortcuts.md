# Keyboard and mouse

## Files and help

| Keys | Action |
|---|---|
| Ctrl+N | New project |
| Ctrl+Shift+N | New from template |
| Ctrl+O | Open |
| Ctrl+S / Ctrl+Shift+S | Save / Save As |
| Ctrl+P | Export PDF report |
| F1 | User guide |

## Editing

| Keys | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+A | Select all |
| Ctrl+D | Duplicate |
| Ctrl+Shift+D | Duplicate with rename |
| Delete or Backspace | Delete the selection |
| Arrow keys | Move the selection one grid step |
| Shift+arrow keys | Move the selection 1 px |
| Ctrl+Shift+L | Auto-layout the diagram |

## View

| Keys | Action |
|---|---|
| Ctrl+0 | Zoom to fit |
| Ctrl+1 | Actual size (100%) |
| Ctrl+= / Ctrl+- | Zoom in / out |

## Mouse

| Action | How |
|---|---|
| Add a device or area | Drag it from the Toolbox, or click it |
| Connect two ports | Drag from a port to a port (or onto a device) |
| Select | Click; Shift+click to add or remove |
| Box-select | Drag on empty canvas |
| Move | Drag a device, or an area by its header |
| Resize an area | Drag its bottom-right grip |
| Pan | Middle-drag, or Space+drag |
| Zoom | Mouse wheel or pinch |
